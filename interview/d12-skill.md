# D12 口述：Skill 是可选说明书

Skill 是说明书，不是去干活的操作。Read 是真的打开文件；Skill 只告诉模型某件事怎么做。一开始只给目录：有哪些说明书、各干什么。全文可能很长，一上来塞进每一封信会又长又贵。模型需要时再点 skill 工具，参数是说明书的名字。点名之后正文才写进账本，下一封信才看得见。没点名，账本里没有这份正文。旁注：Claude Code 的 Skill 也是先发现再按需打开。

公开形态是一个文件夹加 SKILL.md：封面必填 name 和 description，后面是正文；可选 scripts、references。各家扫的目录不同，读的是同一份文件，不认识的字段就跳过，所以同一份能装到 Cursor、Claude Code、Codex、dsh 上。
