# D9 口述：好几个帮手怎么安排

D8 是雇一个帮手收一张小结。D9 是三种雇好几个的办法，都是普通工具，不在主循环里再写 while。Workflow：模型写任务单，先检查抬头再按单雇人，家长只收汇总。Ralph：目标一句话不变，每轮换一个全新帮手，不带家长聊天记录，只看工作区和上一张纸条，纸条是 continue / complete / blocked，家长只收最后一张。Team：组里长期几个人，给队友传话沿用 D6：拍醒用 followup，先放着用 inject，花名册和任务都记在组长账本上。旁注：Claude Code 也有模型写 workflow 脚本这一路；dsh 把 Ralph、Team 同样做成工具插件，不给循环加模式。
